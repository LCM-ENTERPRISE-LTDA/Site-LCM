# VISUAL LANGUAGE SYSTEM — LCM Triad

A identidade visual nasce do **símbolo aprovado** (tríade).  
A logo não é redesenhada. O sistema **estende** sua geometria.

## Origem

Três partes → uma estrutura → união que cria algo maior  
(três fundadores / três módulos / um sistema)

## Unidades derivadas

| Token | Papel |
|-------|-------|
| `--triad-angle` (60°) | Grid e diagonais de fundo |
| `--triad-gap` | Canal entre partes |
| `--radius-triad` | Canto assinatura de botões/chips |
| `--color-brand` `#2F6BFF` | Azul do stroke da logo |
| Ritmo em 3 | Facetas em botões, pontos em divisores, narrativa |
